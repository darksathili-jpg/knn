01 · Modèle mental

Avant KNN : que “voit” la machine ?

Une machine ne voit pas « un drone » ou « une fleur » : elle reçoit une représentation numérique et des exemples déjà étiquetés.

ENTRÉE

Caractéristiques

Des nombres décrivent chaque objet. Ex. une fleur peut être décrite par longueur et largeur de sépale.

EXEMPLES

Classes connues

Chaque exemple possède déjà une étiquette. KNN est donc ici un algorithme de classification supervisée.

SORTIE

Classe prédite

Pour une nouvelle donnée, KNN cherche les voisins les plus proches puis agrège leurs classes.

02 · Exemple guidé

Une prédiction, ligne par ligne.

On commence avec un exemple travaillé avant de te laisser seul. La distance euclidienne est simplement Pythagore appliqué aux coordonnées.

Étape 1
Choisir une mesure de proximité

Pour deux points A(x₁,y₁) et B(x₂,y₂), on utilise : d = √((x₂−x₁)² + (y₂−y₁)²).

Étape 2
Calculer toutes les distances

Pour la cible, on calcule une distance vers chacun des 5 exemples : aucune classe n’est encore choisie.

Étape 3
Trier et ne garder que k

Avec k = 3, seules les trois plus petites distances comptent dans le vote.

Étape 4
Voter

Si les 3 voisins sont CYAN, CYAN, AMBRE, la prédiction est CYAN par 2 voix contre 1.

Commence par identifier ce que signifie « proche » dans l’espace des caractéristiques.

Le voisin le plus proche… selon quelle unité ?

06 · Python

Reconstruis l’algorithme.

Complète les cinq éléments manquants. Il s’agit d’un exercice de lecture et de reconstruction du code, pas d’un interpréteur Python caché.

knn_a_completer.pyPremière NSI
from math import sqrt

def distance(a, b):
    return sqrt(
        (a["x"] - b["x"]) ** 
        + (a["y"] - b["y"]) ** 
    )

def knn(donnees, cible, k):
    assert 1 <= k <= len(donnees)
    distances = []

    for point in donnees:
        d = distance(point, cible)
        distances.append((d, point["classe"]))

    distances.

    votes = {"cyan": 0, "ambre": 0}

    for i in range():
        classe = distances[i][]
        votes[classe] = votes[classe] + 1

    if votes["cyan"] > votes["ambre"]:
        return "cyan"
    elif votes["ambre"] > votes["cyan"]:
        return "ambre"
    else:
        return "égalité"

08 · Esprit critique

KNN est simple. Pas simpliste.

Une bonne utilisation exige de questionner les données, la distance, k et le protocole d’évaluation.

k trop petit

Très local

La frontière peut suivre le bruit et les cas atypiques. La prédiction devient instable.

k trop grand

Trop lissé

Des structures locales peuvent disparaître au profit de la classe majoritaire globale.

dimensions

Proximité fragile

Quand le nombre de caractéristiques devient grand, les distances deviennent moins discriminantes : c’est une facette de la « malédiction de la dimension ».

vote avancé

Pondérer

On peut donner plus de poids aux voisins très proches. Ce n’est pas « toujours meilleur » : c’est un choix à valider sur les données.
