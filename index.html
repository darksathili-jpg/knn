03 · Traduction

Du dessin au Python.

Aucune bibliothèque de machine learning : uniquement des constructions accessibles en Première NSI.

knn.py
from math import sqrt

def distance(a, b):
    return sqrt(
        (a["x"] - b["x"]) ** 2
        + (a["y"] - b["y"]) ** 2
    )

def knn(donnees, cible, k):
    distances = []

    for point in donnees:
        d = distance(point, cible)
        distances.append((d, point["classe"]))

    distances.sort()
    voisins = []
    for i in range(k):
        voisins.append(distances[i])

    votes = {"cyan": 0, "ambre": 0}
    for d, classe in voisins:
        votes[classe] = votes[classe] + 1

    if votes["cyan"] > votes["ambre"]:
        return "cyan"
    elif votes["ambre"] > votes["cyan"]:
        return "ambre"
    else:
        return "égalité"
Lecture guidée

Ce code raconte exactement la simulation.

  1. `distance` transforme deux coordonnées en un nombre comparable.
  2. La boucle parcourt toute la table d’exemples.
  3. Chaque couple (distance, classe) est stocké dans une liste.
  4. `sort()` place naturellement les plus petites distances en tête.
  5. La boucle `for i in range(k)` garde les k premières lignes, sans utiliser les tranches Python qui ne sont pas exigibles en Première.
  6. Le dictionnaire `votes` compte les classes observées.

Question NSI : si la table contient n points, combien de distances faut-il calculer pour classer une nouvelle donnée ? → n.

Ce qu’il faut comprendre

KNN ne “comprend” pas un drone.

Il applique une règle sur une représentation numérique. Si on change les caractéristiques, leur échelle ou les données d’exemple, la décision peut changer.

Machine learning ≠ magie. Un résultat dépend des données, de la représentation choisie et des paramètres de l’algorithme.

06 · Esprit critique

Quand KNN se trompe.

Comprendre un algorithme, c’est aussi savoir dans quelles conditions sa réponse devient fragile.

Échelle des variables

Une variable mesurée de 0 à 10 000 peut écraser une autre mesurée de 0 à 10 dans le calcul de distance.

Choix de k

Un k très petit est sensible au bruit ; un k très grand peut lisser des groupes pourtant distincts.

Données biaisées

Si les exemples ne représentent pas correctement la situation réelle, le vote reproduit ce déséquilibre.

Beaucoup de dimensions

Avec de très nombreuses caractéristiques, la notion de “proximité” devient moins informative.
